## 100-word description

ModelScope helps students move beyond memorizing equations by testing where scientific models and approximations stop adequately matching measurements. Explore Spring, Pendulum, Beer–Lambert, and Sensor systems, then inspect linked graphs, residuals, and evidence. Custom CSV, pasted tables, and manual measurements use the same deterministic pipeline: baseline fitting, penalized segmented comparison, sustained disagreement, and an influence safeguard. Results distinguish supported, ambiguous, and no clear transition, with careful sensitivity ranges and reproducible JSON exports. Gemini proposes supported setups requiring confirmation and explains existing findings; it never determines the scientific result. Raw measurements stay local during normal analysis. AI explains. The analysis engine decides.

## 250-word description

ModelScope helps students understand scientific equations as models with assumptions and limited valid regimes. Instead of treating an attractive fit as the end of an experiment, learners investigate where measurements begin systematically disagreeing with a reference.

Four scientific systems introduce the same question through Hooke’s law, the small-angle pendulum approximation, Beer–Lambert concentration response, and sensor calibration. A graph-first workspace connects measurements, reference predictions, residuals, comparisons, and findings. Students can also import CSV, paste tables, or enter their own observations, explicitly mapping variables, declaring units, and choosing a justified response scale.

The analysis is deterministic. ModelScope compares a baseline against continuous segmented alternatives, penalizes additional complexity and candidate search, requires sustained same-direction residual disagreement, and checks influence. Findings distinguish supported, ambiguous, no clear transition, and insufficient sampling. Reported transition sensitivity ranges are not confidence intervals, physical failure points, or proof of a mechanism. JSON exports preserve numerical evidence and provenance.

Gemini has two bounded roles. The Setup Assistant proposes supported configurations from a description and column headers, requiring student review and confirmation. Explain Evidence translates an existing finding into accessible language. Neither can fit the model, choose breakpoints, invent uncertainty, or change support states. AI explains. The analysis engine decides.

Normal analysis keeps raw measurements in the browser. Optional AI sends requested setup or evidence context, which should exclude sensitive information. Built-in data is synthetic and educational impact has not been measured. The public prototype combines inspectable scientific reasoning, responsible assistance, responsive design, and 306 passing tests to support model literacy.
